# 手动测试清单

`scripts/e2e.ps1` 已经覆盖了协议和剪贴板的主要行为（模拟手机，走本机回环）。
下面这些需要真机或人眼确认。

## 真机链路

- [ ] 第一次启动时 Windows 防火墙弹窗：勾选「专用网络」并允许
- [ ] iPhone 手动运行快捷指令，能收到「没有新内容」之类的提示（说明连通了）
- [ ] 碰 NFC 标签，快捷指令自动运行，不需要确认，也没有「正在运行自动化」的横幅
- [ ] 电脑复制文字 → 碰标签 → iPhone 上粘贴得到同样的文字
- [ ] iPhone 复制文字 → 碰标签 → 电脑 Ctrl+V 得到同样的文字
- [ ] 两边都复制 → 碰标签 → 弹出菜单；「发送」和「接收」两个方向都正确
- [ ] 含换行和中文、emoji 的文字，两个方向都保持原样

## Win+V 历史（确认「剪贴板历史」已开启）

- [ ] iPhone 发来但**没粘贴**的内容，2 分钟后电脑剪贴板恢复原样，Win+V 里没有它
- [ ] iPhone 发来且**粘贴过**的内容，出现在 Win+V 历史里（只有一条）
- [ ] 恢复原内容后，Win+V 里没有多出一条重复的旧内容

## 不同的粘贴目标

以下每个程序都要试一次：粘贴 iPhone 发来的内容能拿到文字，之后会进入 Win+V 历史。

- [ ] 记事本
- [ ] 浏览器地址栏和网页输入框
- [ ] Word / WPS
- [ ] 微信 / QQ 电脑版
- [ ] Windows Terminal

## 可能误判「已粘贴」的程序

iPhone 发送后**什么都不做**，2 分钟后看剪贴板有没有恢复。如果没恢复，说明有程序提前读取了剪贴板，需要记下是哪个程序。

- [ ] 第三方输入法（搜狗、微信输入法等）的剪贴板功能
- [ ] 其他剪贴板管理工具（Ditto 等）

## 恢复各种原内容

先在电脑上复制下面这些东西，然后让 iPhone 发一段文字过来且不粘贴，等 2 分钟后原内容应该还能正常粘贴：

- [ ] 资源管理器里复制的文件（粘贴后是复制，而不是剪切）
- [ ] 截图工具复制的图片
- [ ] 网页上复制的带格式文字（粘贴到 Word 保留格式）

## 托盘和启动

- [ ] 托盘图标在深色和浅色任务栏上都看得清
- [ ] 「配对信息…」显示地址和密钥
- [ ] 「开机自动运行」勾选后重新登录 Windows，TapClip 自动启动
- [ ] 重启资源管理器后托盘图标会重新出现
- [ ] 重复启动 TapClip 时会提示「已经在运行了」
