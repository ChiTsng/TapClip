# TapClip 功能规格（v1）

在桌角贴一张 NFC 标签。iPhone 碰一下标签，就能和 Windows 电脑交换一段剪贴板内容。

## 核心模型：一个共享项

- 两台设备只共享**一个当前项**，谁最后复制就是谁的。不同步历史。
- 只同步**文字**（包括链接）。
- 只在**同一局域网**内工作。
- 带「不要同步」标记的内容一律跳过，比如密码管理器复制的密码。判断依据是 Windows 的这几个剪贴板格式：`ExcludeClipboardContentFromMonitorProcessing`、`Clipboard Viewer Ignore`，以及值为 0 的 `CanIncludeInClipboardHistory` 或 `CanUploadToCloudClipboard`。
- 共享项的有效时间默认 **2 分钟**，在配置里可调。

## 电脑端（完全无感，开机自启，后台运行）

### 电脑上复制

复制时一切照常。TapClip 只记下内容和时间，这一项在有效时间内可以被 iPhone 取走。

### 收到 iPhone 发来的内容

内容先挂到电脑剪贴板上，不进 Win+V 历史，也不上云剪贴板。这里用的是 Windows 的延迟提供机制：真正粘贴时才交出数据，所以能知道有没有用上。

| 情况 | 结果 |
|---|---|
| 有效时间内粘贴了 | 变成一条普通记录，进入 Win+V 历史 |
| 有效时间内没粘贴 | 自动恢复电脑原来的剪贴板，不留痕迹 |
| 期间电脑自己又复制了新东西 | 以新复制的为准，iPhone 这条作废 |

## iPhone 端（亮屏解锁后碰一下桌角的标签）

碰一下时自动判断方向，并弹通知告诉你这次做了什么：

| 情况 | 碰一下的结果 |
|---|---|
| 只有 iPhone 有新复制 | ⬆ 发送到电脑 |
| 只有电脑在有效时间内有新复制 | ⬇ 取到 iPhone 剪贴板 |
| 两边都有 | 弹出二选一菜单：发送 / 接收 |
| 两边已经是同一段内容 | 提示「两边已经是同一段内容」 |
| 两边都没有新内容 | 提示「没有新内容」 |

「新复制」的判定规则：

- iPhone 上的内容如果刚从电脑取来，不算新。
- iPhone 上的内容如果以前发过，但电脑上已经没有了（比如过期被恢复），碰一下会**重新发送**。遇到这种情况时，如果电脑在有效时间内又有新复制，因为电脑那条更新，所以取电脑的。
- iPhone 取到的内容一直保留，不会过期。碰标签本身就表示要用，而且 iOS 没有剪贴板历史可以污染。
- iPhone 的剪贴板只在碰标签那一刻读取一次。

## 已知限制（需要实测）

- **「粘贴过」的判断可能不准：** 电脑上个别程序会提前读取剪贴板，这时内容会被当成「用上了」。
- **原内容尽力恢复：** 文字、图片、文件一般能恢复；GDI 句柄类和 OLE 私有格式会跳过。快照上限 64 MB。
- **行尾转换：** iPhone 用 `\n`，电脑用 `\r\n`，传输时会自动转换。
